三、beta以及or值置信区间计算公式

所有计算公式得到beta和se值后，都可以用这个来计算出beta和or的置信区间

lo_ci = b - 1.96 * se

up_ci = b + 1.96 * se

or = exp(b)

or_lci95 = exp(lo_ci)

or_uci95 = exp(up_ci)

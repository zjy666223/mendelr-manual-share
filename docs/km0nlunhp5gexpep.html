MendelR包是一个完整的分析流程包，零基础学员也可以直接一键分析，告别各种繁杂的代码操作，让分析变得更加简单便捷。

假如数据是X，各种参数+算法是b，结果是Y，那么整套分析流程就变成了Y=bX。

只要数据和参数算法是相同的，不管用什么代码，都是能够做出来结果的，也可以不用R语言，用python，C++等编程语言都是可以的。

MendelR目前是团队创建的一键代码包，没有发布到任何相关的文献上，因此不需要在文章中引用。

其实做mr分析，最重要的是各种mr分析算法，比如ivw的底层实现，究竟是怎么计算的，原理是什么，但是这些对于我们发MR文章的使用者来说，不用过多的理解算法是怎么实现的，只需要知道怎么使用，就可以了。

关于各种算法实现，如果需要在文章描述，可以引用对应的文献：方法学部分的权威参考文献引用站内引用引用方法学的时候，引用该方法对应的原文逆方差加权法-inverse-variance weighted (IVW):Using published data in Mendelian randomization: a blueprint for efficient identification...

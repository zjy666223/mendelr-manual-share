待MendelR版本更新到10.0

支持本地数据，支持大量数据的批量分析

一、环境准备

准备好后分别检查是否安装MRlapPro包成功，LD文件夹是否在工作目录下。

前者用于计算MRlap的主要功能，后者主要用来进行本地连锁不平衡clump。

注意：

  • MRlapPro包是基于MRlap和GenomicSEM包的魔改版
  1. 增加了读取文件的速度
  2. 将部分代码修改成效率更高的替代版本
  3. 修改了GenomicSEM中标准化数据时，无用反复读写文件带来的内存消耗，时间消耗
  4. 将必要的文件直接封装到了包里
  5. 删除了例子里的BMI和SBP 减少安装MRlapPro包的时间

耗时上，可以大概减少原MRlap包的90%无用耗时，主要目的是为了支持大量的文件批量分析。

MRlapPro包已上传到github:https://github.com/flash0926/MRlapPro

使用该包时需要引用该代码包。

搭配MendelR可以构建一个完整批量MRlap流水线功能，并将结果直接输出到本地目录保存。

还有一个问题 MRlap的流程中的mr（ivw）分析，snp的流转流程是

暴露筛阈值和结局的snp取交集后，再做的clump

而我们做MR的标准流程，应该是暴露筛阈值，先clump，再和结局的snp取交集

这里就会有一个问题，就是在MRlap中，暴露和结局先取交集，会导致snp减少，然后clump时会有较大的差异（snp会不同）

这里的差异，就会导致ivw的分析结果，和我们自己做的不一样

所以，如果纠结的同学，请自行修改mr部分的流程源码，在run_MR.R内

二、数据准备

需要按照模板snp的表头规整好本地数据

除了常规的SNP beta se pval 外，需要有chr pos samplesize数据，查看模板snp的文档准备好

因为需要同时进行LDSC，用来计算矫正偏移，所以只能使用本地数据。

代码可以支持任意数量的文件进行分析


四、结果解读

输出文件有三个

1.GeneticArchitecture遗传结构结果

2.LDSC 结果

3.MRLap的主要矫正结果（主要看这个结果）

effect 为 ivw的beta值，如果是二分类结局，可以自己转换成or值=exp(beta)

se 为ivw的标准误

p值为ivw的pval值

ovserved为原ivw分析值

corrected 为假设的MRLap（LDSC）矫正后的结果

主要看p_difference是否有统计学差异 p_difference<0.05

如果p_difference<0.05 则代表人群重叠对结果影响很大，要参考corrected后的结果

如果p_difference>0.05 则影响不大，看ovserved或corrected都可以

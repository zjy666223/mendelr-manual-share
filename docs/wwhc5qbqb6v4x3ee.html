原理：多变量孟德尔随机化对纳入的不同暴露因素进行校正的作用。

​

假设我们想要探究BMI和血脂（这2个暴露）对糖尿病的影响。

​

接下来，我们可以使用单变量孟德尔随机化方法来评估BMI与糖尿病之间的因果关系。通过选择与BMI相关的SNP作为工具变量，我们可以利用这些SNP对BMI的影响来推断BMI对糖尿病的影响。这样，我们就可以得到BMI对糖尿病的因果估计。

​

然后，我们可以使用多变量孟德尔随机化方法来进一步校正血脂对BMI与糖尿病之间关系的影响。通过选择与血脂相关的SNP作为额外的工具变量，我们可以将血脂作为混杂因素引入回归模型中，以控制其对BMI与糖尿病之间关系的干扰。这样，我们就可以得到在考虑血脂的情况下，BMI对糖尿病的调整因果估计。

​

筛选snp的原理：

假设有暴露A、B、C

  1. 各自进行阈值筛选+clump后，得到各自的SNP
  2. 以暴露A为例，暴露数据A，会扩充B、C两个暴露第一步中对应的rsid的数据
  3. 每个暴露做完第二步后，再次分别clump，得到最终的SNP
  4. 每个暴露的SNP是完全一样的，只是beta se pval数据不同
  5. 得出的最终结果中，SNP数量是一致的，但是不是每个SNP的pval都是小于阈值的，因为，有部分SNP是在B暴露中显著，但是在A暴露中不显著，这个就是多变量的核心原理，纳入别的暴露的显著的SNP进行数据矫正。

注意：如果clump有问题，请自行切换本地clump👉本地连锁不平衡Clump以及更改人群站内引用做孟德尔随机化过程中，提取工具变量要去除连锁不平衡，保留一定区域内具有与性状显著相关的SNP但是有时候由于网络原因/服务器原因，或者你的暴露数据是本地数据，或者工具变量太多，网络带宽不足，在线clump会出现稳定性问题，即跑分析过程中容易超时中断。为了解决这个问题，专门增加了一个参数！使用这个...

没法判断的报错，请截图找咨询的老师，截图要全面，不要只截一小部分，02.如何截图站内引用截图工具可以依赖微信，QQ，等有截图功能的软件这里推荐几个性能强大的截图软件，不仅有截图的功能，还可以将截图贴到屏幕上，以及其他扩展功能Snipaste - 截图 + 贴图PixPin 截图/贴图/长截图/文字识别/标注 | PixPin 截图/贴图/长截图/文字识别/标注回归到如何提问上面，...方便判断问题。

注意1：没有直接赋值的字符串，请用双引号括起来，否则语法错误（"字符串内容"）

！！！只要不是数值，或者你自己声明的变量，都是字符串类型，都要加双引号

什么是自己声明的变量？ a=1 这样a就是你自己声明的数值为1的变量

注意2：把本地文件的文件名尽量改短，且不要有空格，避免文件名过长过复杂，R语言抽风

注意3：R4.3以上，对中文路径或者文件名不是很兼容，容易抽风识别不了，请改成英文

特别注意：文件和文件夹名，路径，都不能有空格，+-*&!@#$%^&*()等特殊符号，路径不要太长，尽量简单。

1.提示不存在的包，没有这个DLL等 缺少依赖包的情况

缺少textshaping包，有可能是被360误删了的，重新装一下，不要让360清理这个文件

2.could not find function， 尝试library(MendelR)，尝试更新，其他R包的方法也同理

3.自动更新时 提示是否更新其他的R 包 根据提示 输出 n 然后回车即可

4.网络错误码502 服务器没响应的返回 等代码包自动重试5.IEU服务器502的解决方案引用链接问题：最近大家在做孟德尔分析的时候，经常会遇到服务器502的错误，这是因为如果使用IEU的在线数据，是要通过对应的服务器访问的，而目前因为服务器无响应，连接过多等原因，导致出现502或者503错误。这个在网络错误中是一种比较常见的存在，俗称服务器挂了，原因可能是服务器残留的TCP访问链接过多，...

5.提示文件不存在等

检查工作目录，或者提示的目录里面是否有对应的文件，将文件拖放到对应目录，或者修改工作目录

执行 list.files() 查看本地是否有这个文件，请对清楚文件名。

6.文件名中不能有非法字符，中文，空格，-横线

7.提示载入了名字空间 但是版本不对（依赖包版本需要更新）

需要安装到特定版本以上的R包

原因：包相互依赖会限定依赖包的最低版本，如果版本不够，则会提示报错

例子：提示gdtools需要0.3.3版本以上

1.先卸载，搜索到这个包，卸载，重启RStudio

2.重新装

特别的，如果无法安装成功，可以用另外的包来辅助安装

比如这个Matrix包，用常规的命令无法安装

8.ppt画图引擎错误，无法输出

在方法里面增加write_ppt=F 参数，将把图的输出改成pdf

9.cannot alocate vector of size 219.0 Mb

提示这个则表明电脑配置的内存不足，读取不了本地文件

1.提升配置，添加内存

2.更改系统设置中的虚拟内存数量，提供部分内存给R读取文件
